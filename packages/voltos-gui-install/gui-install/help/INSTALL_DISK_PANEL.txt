Disk


Select the disk VoltOS is installed on. The disks of this computer are shown with their size and type; point at a disk to see its vendor and device name. The disk the live medium was started from is not shown.

VoltOS needs a disk of at least 16 GB; 32 GB or more is recommended, so there is room for boot environments and snapshots.

CAUTION: The whole disk is erased. VoltOS creates a new GPT partition table with an EFI system partition and a ZFS pool (zroot) on the rest of the disk. Other operating systems and data on the disk are removed.

VoltOS installs on computers that start with UEFI firmware.
