Welcome to the VoltOS Installer


This installer puts VoltOS on a disk of this computer. It copies the live system you are running, so everything you see here is what gets installed, and no network connection is needed.

CAUTION: VoltOS is installed on a whole disk. Everything on the disk you choose is erased.

VoltOS uses a ZFS file system with boot environments. Before every software update a snapshot of the system is taken, and the boot menu (ZFSBootMenu) can start any earlier boot environment or snapshot, so a bad update can always be undone.

To view the help for any screen of this installer, select the Help button on that screen.

This installer does not upgrade an existing VoltOS installation. To update an installed system, run "doas pacman -Syu" on it.

Note: You can end the installation on any screen up to Installation by selecting the Quit button.
