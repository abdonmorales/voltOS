Time Zone, Date and Time


Select the time zone of this computer. You can click a city near you on the map, or choose a region, a location and a time zone from the lists below the map.

Using the map:
  - Click the map to zoom in; right-click to zoom out.
  - Drag the map to move it.
  - Point at a city to see its name; click it to select its time zone.

Then check the date and time. If they are wrong, set them; the clock of this computer is set when you continue to the next screen.
